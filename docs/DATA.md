# 数据分层、恢复与统计口径

## 原始数据（本机 / 云端运行期间）

- `baidu.sqlite3`：完整 API 历史，含 IP 计费明细。
- `csv/`：所有原始 CSV 及关键词汇总。
- `inventory_snapshots`：计划、单元、关键词清单的日期快照。
- `report_rows`：报告名、行键、日期、原始 JSON、抓取时间。
- `report_coverage`：成功完成的请求覆盖日期范围。
- `status.json` 与 `runs.jsonl`：采集结果、历史运行和授权提醒。
- `work/`：最初的调查与开发资料；仅进入加密备份，不作为运行依赖。

`vault.py` 在内存中压缩并使用 AES-256-GCM 加密，带随机 12 字节 nonce、认证标签及逐文件 SHA-256 清单。SQLite 用一致性备份 API 拍摄快照。恢复前先认证、验证清单与路径，默认不覆盖不同的现有数据。恢复密钥不在 Git 中。

## 公开历史

`data/public.sqlite3` 从原始 JSON 重新建库，不是删除字段后直接复制旧数据库，因此已移除的 IP 不残留在 SQLite 空闲页。公开层包括：

- 15 类统计报告的全部历史行与当前清单；现有配置一共 16 类，其中无效点击是第 16 类。
- IP 计费报告按日期、计划与设备汇总，保留过滤前、无效及计费的点击数和金额，去掉访客 IP。
- `data/csv/`：同一公开数据的 CSV。
- `data/status.json`：最近运行结果；无令牌。
- `data/manifest.json`：公开导出说明、报告条数与覆盖范围。

公开数据是实际广告统计，并非演示数据。仓库与 Pages 都会向访客公开这些统计、关键词、搜索词与广告文案。完整原始行可通过加密备份恢复。

## 口径

- 关键词与搜索词分别保存；相同字面但不同关键词 ID 不合并成一个词。
- 当前本体 / 影子清单不能相加作为关键词总量。
- 当前质量度、出价和状态是快照，不等于历史值。
- 缺少记录显示 `—`，不能自行补成已确认的 0。
- CTR 与 CPC 从总量重新计算；不平均每日比率。
- 不同维度报告不能相加。发布前比较相同覆盖日期的消费与点击；若不一致则阻止自动发布，保留上一版公开页面供查看。
- 无效点击金额和计费金额分别统计；过滤前 = 无效 + 计费，不将无效金额误写成追加损失或已到账退款。
- 0 次 API 转化不证明 0 次实际询盘。CRM、网站会话、演示与成交不在当前 API 数据中，尚待接入。
- 公开页面中无效点击行数会因汇总而少于原始 IP 明细；合计应相同。

初始快照于 2026-10-29 采集，查询范围 2026-07-31 至 2026-10-28；实际首个表现日是 2026-09-18。此后按工作流和页面状态中的最新日期为准，不把初始合计当成永远固定的期望值。
