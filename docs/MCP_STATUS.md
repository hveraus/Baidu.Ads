# MCP 实现与验收状态

更新：2026-11-17。**本地实现及现有数据核对已完成，生产 MCP 尚未部署。** Ken 已选择先完成本地开发和现有核对。本文记录验证范围，不授权真实广告写入或创建收费资源。

## 当前可用的软件能力

- 46 个 MCP 工具，支持 stdio 和需要 OAuth 的 Streamable HTTP。
- 三账号、12 类广告报表，包含设备、地域、时段、创意等维度；支持精确筛选、排序、分页、区间对比和数据覆盖说明。
- 网站全站/付费行为及固定版本的 CLI、WeCom 私有汇总读取；明确来源和归因边界。
- 版本化草稿、网页审批、幂等执行队列、执行前实时核验、逐项回读、未知结果锁定和重新审批的补偿方案。
- 16 类严格广告操作契约，包括预算、手动/智能出价字段、启停、否词、定向、新建和创意修改。是否能够真实执行由各账号独立验证的能力决定。
- 限量、限时、登录下载的导出；订阅、站内通知、后台缓存刷新、历史模拟和待审批建议。
- 独立预审批自动规则：固定暂停、恢复、计划预算、手动出价；限制对象、金额、次数、冷却期、有效期，并检查停止条件。

两个执行开关默认关闭，示例不授予 `policies:automate`。本次开发没有更改真实广告。完整工具目录见 [MCP README](../services/mcp/README.md)，部署方式见 [独立部署与回退](../services/mcp/DEPLOYMENT.md)。

## 已通过的验证

| 验证 | 结果 | 能证明什么 |
|---|---|---|
| MCP 独立测试 | 193/193 | 查询口径、协议、OAuth/撤销、网页保护、队列与模拟供应商、自动规则、并发/恢复 |
| 独立读取服务测试 | 8/8 | 只读身份读取、密码验证、版本失效、合成加密汇总及路径/操作限制 |
| 真实 MCP 数据交叉核对 | 69/69 | 实际 SDK 握手和工具调用，按相同维度/日期对照百度报表接口及已登录网页捕获 |
| 本地故障注入 | 9/9，已包含在 MCP 测试中 | 进程终止、读取服务停止/超时、损坏缓存/状态、不兼容/不完整来源不会改动合成核心数据 |
| 独立执行 worker 演示 | 成功，生产调用为 0 | 草稿、审批、入队、模拟提交及回读链路可运行 |
| 发布检查 | 通过 | 公开文件检查、差异格式、独立制品逐文件摘要；排除私有输入和本地状态 |

193 + 8 为 201 项独立测试总数；故障注入及安全审查测试不重复加总。远端 Linux/Windows CI 结果以本次提交对应的 GitHub Actions 为准，不能用本地 macOS 通过代替 Windows 实机验收。

数据核对使用三个账号的账户/关键词报告，以及其他十类报告；另外核对网站精确区间、付费行为和缺失值。Computer Use 在 Safari 中查看了已登录的生产报表和百度统计全部来源趋势页。

核对确认：生产总览使用**关键词报告**，默认 MCP 摘要使用**账户报告**；两类报告的展现可能不同。各自对应的上游结果一致，MCP 摘要已同时提供来源、差值与覆盖信息。不同维度不相加，也不强行改数使它们相等。

CLI/WeCom 仅完成“已登录网页捕获 → 明确标识的测试身份桥接 → HTTP MCP”的计算一致性检查，**不等于私有上游 API 或生产身份桥接的独立实机核对**。

## 尚未完成的生产验收

1. 独立 MCP 主机、私有入口、证书和 OS 资源限制；没有购买或部署新主机。
2. 真实 Agent 客户端的 OAuth 登录/续期/撤销，Windows 服务身份、DPAPI 和 ACL。
3. 私有源独立上游核对与真实身份桥接。远程桌面不可操作时未绕过此门槛，用户选择先完成本地工作。
4. 完整核心采集周期、真实故障注入、同负载 P95 对比及共享供应商配额争用。
5. 每账号、每动作的真实写权限、枚举与限制验证；只可针对另行明确授权的测试对象执行。

父级级联删除缺少已验证的子树并发契约时不能执行。新建请求超时且没有可信的上游创建来源证据时保持未知与锁定，不能凭名称或人工候选 ID 认领，也不盲目重发。详情见 [执行契约与限制](../services/mcp/EXECUTION.md)。

外发通知、CRM/ROI 和触发核心采集在完整规划中是单独接入项目，目前没有配置对应供应商或核心命令契约。

## 复核与数据保密

在各服务目录使用各自锁定的环境：

```sh
uv sync --frozen
uv run --frozen python -m unittest discover -s tests -v
```

真实捕获核对脚本为 `services/mcp/scripts/verify_capture.py`；本地故障验收脚本为 `services/mcp/scripts/verify_isolation.py`。私有输入与明细结果留在忽略的 `work/mcp-verification/`。浏览器捕获 ID 不是 ECS release ID。

仓库提交仅保存代码、文档、合成测试及锁定依赖；不保存生产凭据、当前计数、捕获 HTML、运行数据库、原始 CSV 或验收日志。独立制品由 `services/package_services.py` 的白名单产生，核心系统不依赖 MCP 构建、安装、运行或发布。
