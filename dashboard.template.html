阅读这份报表前，先理解几个口径

关键词与搜索词
关键词是你设置的投放对象；搜索词是用户实际输入的内容。一个关键词可能触发多个搜索词，一个搜索词也可能由多个关键词触发
转化为 0 意味着什么
只能确认百度 API 在当前口径下未返回转化记录，不能直接证明没有真实询盘。请结合网站表单、电话、CRM 及转化追踪配置核对
当前清单与历史表现
关键词状态、质量度、出价和计划暂停状态来自最新清单；展现、点击和花费来自所选历史日期。已删除但曾投放的关键词仍会保留历史记录
缺失与零
有报告记录但数值为 0，会显示 0；当前清单存在但没有报告记录的词，会显示 —，避免把缺失数据当成已确认的零
比率如何计算
点击率＝点击总数 ÷ 展现总数；平均点击价格＝消费总额 ÷ 点击总数。按合计计算，不平均每日比率。不同明细表是同一花费的不同切面，请勿相加
时间与更新
北京时间，每日采集截至昨天的数据，回补最近7天以覆盖迟到转化。自动任务通过 Codex 在本机运行，需要本机与 Codex 可运行且有网络。页面为本地快照；采集完成后点“刷新报表”
